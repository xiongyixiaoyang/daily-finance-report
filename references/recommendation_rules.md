# 推荐规则（股票 + ETF）

> 这些规则是 2026-07 至 2026-08 期间经用户多轮反馈迭代出的「血泪教训」，
> 必须严格遵守。所有推荐都是给个人实盘投资赚钱用的参考，必须可执行、可回溯。

---

## 股票推荐规则

### 1. 仅限 A股 / 港股
- **只推荐在A股或港股上市的公司**。
- 美股上市公司（英伟达、特斯拉、苹果、微软、谷歌等）**一律不得出现在股票推荐中**。
- 美股公司只能在「深度观察」里作为产业/行业分析对象出现。

### 2. A/H 双上市标的 → 默认选 H 股
- 除非 **A/H 溢价率 < 15%**（基本平价），或明确说明原因（如H股流动性极差），才可选 A 股。
- 推荐前必须用腾讯行情 API 拉取 A/H 两边价格计算溢价率：
  ```
  溢价率 = A股价格 / (H股价格 × 汇率) − 1
  ```
- 推荐中注明：「A/H 溢价 X%，选H股因估值更低」。

### 3. 延续跟踪 > 新增推荐
- 先读推荐跟踪档案（`推荐跟踪档案.md`）。
- 之前推荐的股票若逻辑仍然成立（基本面/催化未变），**优先追加更新**，而非推新票。
- 逻辑已兑现或破坏 → 说明终止跟踪的原因。
- 新增推荐须与历史推荐有连贯的逻辑主线，**避免每天换赛道**。

### 4. 数量与质量
- 不超过 **2 只**。没有十足把握写「暂无明确推荐」，不硬凑。

### 5. 目标价必须有依据
- 用腾讯行情 API 拉取该股票实时价核对。
- 目标价不得偏离当前价超过 **30%**。
- 拿不到实时价就不写目标价，改写估值区间。

### 6. 不编造
- 推荐逻辑必须引用当日采集的新闻/数据，不得凭空编造。

## ETF 推荐规则

### 1. 数量
- 最多 **2 只** A股行业或宽基指数 ETF（沪深300ETF、科创50ETF、半导体ETF、新能源车ETF、消费ETF等）。
- 没有明确看好的 → 写「暂无明确推荐」。

### 2. 连贯性（与股票同等重要）
- 先读推荐跟踪档案，之前推荐过的 ETF 若逻辑仍成立（行业景气/估值分位/政策催化未变），**优先延续跟踪更新**（上次推荐价→当前价→盈亏），而非每天换标的。
- 逻辑已兑现或破坏才终止，并说明原因。
- 新增 ETF 须与档案内已有推荐保持主线连贯。

### 3. 价格核实
- 用腾讯行情 API 拉取该 ETF 实时价核对（如 sh510300 沪深300ETF、sh588000 科创50ETF）。
- 无法核实价格的 ETF 不推荐。
- 同一标的只推一个 ETF。

### 4. 完整实操框架（每条必含）
每条 ETF 推荐必须包含以下字段，这是给个人实盘用的，必须可执行：

| 字段 | 要求 |
|------|------|
| **核心逻辑** | 1-2句，引用当日新闻/政策/资金面/估值分位 |
| **配置权重建议** | 占个人权益仓位的百分比区间（如10-15%） |
| **目标价/目标区间** | 基于估值锚定（指数PE分位对应点位）+ 技术位点（前高/均线/筹码密集区）测算 |
| **止盈止损建议** | 止盈位、止损位、触发条件及执行方式 |
| **逻辑依据** | 估值/技术/资金面数据支撑 |
| **跟踪记录** | 上次推荐价→当前价→盈亏（如有） |
| **风险提示** | ⚠️ 具体风险 |

## 推荐跟踪档案格式

文件：`AI 工作区/成果文件/全球财经日报/推荐跟踪档案.md`

每条记录追加一行：
```markdown
| ${DATE} | [代码] | [名称] | [推荐价] | [目标价/区间] | [止盈止损] | [最新价/盈亏] | [逻辑摘要+权重建议] |
```

已有推荐的价格更新时，同步更新最新价和盈亏字段。
