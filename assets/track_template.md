# 推荐跟踪档案格式

文件位置：`AI 工作区/成果文件/全球财经日报/推荐跟踪档案.md`

## 用途

记录每次推荐的标的、价格、目标、逻辑，实现：
- **连贯性**：下次推荐时先查档案，逻辑未变就延续跟踪
- **可回溯**：任何时间都能看到每只票的完整历史
- **可评估**：盈亏一目了然，验证推荐质量

## 表头

```markdown
| 日期 | 代码 | 名称 | 推荐价 | 目标价/区间 | 止盈止损 | 最新价/盈亏 | 逻辑摘要+权重建议 |
|------|------|------|--------|------------|---------|------------|------------------|
```

## 记录规则

### 新增推荐
```markdown
| 2026-08-07 | 688981 | 中芯国际 | 128.50 | 135-150 | 跌破120止损 | — | 新增推荐：AI算力主线，SK海力士扩产+发改委政策双催化 |
```

### 延续跟踪（同日更新）
```markdown
| 2026-08-08 | 688981 | 中芯国际 | 128.50 | 135-150 | 跌破120止损 | 128.50 (0.00%) | 延续第2日：逻辑未变，目标维持 |
```

### 终止跟踪
```markdown
| 2026-08-03 | 601857 | 中国石油 | 11.05 | — | — | 10.63 (+14.67%) | 终止跟踪：地缘溢价兑现，触发止盈纪律（累计+19.2%） |
```

## 关键字段说明

| 字段 | 说明 |
|------|------|
| 推荐价 | 首次推荐时的价格 |
| 目标价/区间 | 当前有效的目标，偏离当前价不超过30% |
| 止盈止损 | 触发条件 + 执行方式 |
| 最新价/盈亏 | 相对最近一次推荐价的涨跌幅 |
| 逻辑摘要 | 一句话逻辑 + ETF需附权重建议 |

## 维护纪律

1. 每次生成日报时，先读档案再写推荐。
2. 逻辑未变 → 延续跟踪，不推新票。
3. 逻辑破坏/兑现 → 明确标注终止，说明原因。
4. 所有价格用脚本从行情API拉取，不手写。
